# 🌴 Herd Attendance QR

A modern, QR-based employee attendance system built with **Laravel** and **React**. This application provides a fast and efficient way to manage attendance using QR codes.

---

## 🚀 Main Features
*   **QR Scan:** Quick check-in and check-out for employees.
*   **Admin Dashboard:** Real-time summary of employee attendance.
*   **Employee Management:** Easy way to add, update, or remove staff data.
*   **Responsive Design:** Works perfectly on both mobile and desktop.

## 🛠️ Tech Stack & environment
I used the latest stable versions and modern development tools:

*   **Development Environment:** [Laravel Herd](https://herd.laravel.com) (Pre-configured PHP, Nginx, and Node.js)
*   **Framework:** Laravel 13 (PHP 8.3+)
*   **Frontend:** React 18/19 (Integrated via Vite)
*   **Database:** MySQL 8.0
*   **Styling:** Tailwind CSS

## Backend Setup
* **Open the project folder in your terminal.**
* **Run composer install.**
* **Run cp .env.example .env and configure your DB.**
* **Run php artisan migrate.**
* **Note: No need for php artisan serve if you are using Herd's site isolation or linked sites.**

## Frontend Setup
* **npm install**
* **npm run dev**
